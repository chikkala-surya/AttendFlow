# AttendFlow HRMS

AttendFlow is a Flask-based Employee Attendance Management System designed for tracking employee attendance, generating reports, and managing employee records.

## Features

* Admin Login System
* Employee Management (Add, Edit, Delete)
* Employee Search
* Attendance Tracking
* Attendance Calendar View
* Monthly Attendance Reports
* Attendance Statistics
* CSV Report Export
* Dashboard Analytics
* Responsive Apple-inspired UI

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* Jinja2
